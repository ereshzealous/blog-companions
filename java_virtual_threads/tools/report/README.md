# Benchmark report assets

`report.css` and `masthead.html` preserve the saved report's layout. `fonts.css` embeds
the existing Lilita One, Nunito, Comic Shanns and Cascadia font data so the generated HTML
works offline. The renderer adds the benchmark panel styles from `../benchmark_report.py`.

Original font licenses are included in `licenses/`:

- [Lilita One](https://github.com/google/fonts/tree/main/ofl/lilitaone): SIL Open Font License and font log.
- [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito): SIL Open Font License.
- [Comic Shanns](https://github.com/shannpersand/comic-shanns): MIT License.
- [Cascadia Code](https://github.com/microsoft/cascadia-code): SIL Open Font License.
