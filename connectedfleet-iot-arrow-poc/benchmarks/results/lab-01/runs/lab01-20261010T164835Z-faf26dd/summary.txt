HOW TO READ THIS
- Same-process microbenchmark on one machine: it shows where time goes inside one worker, not pipeline, Kafka or ClickHouse throughput.
- decode and validate run identical shared code in both paths.
- build is the Arrow path's extra conversion step (rows -> typed arrays); the row path has no build phase.
- serialize emits different formats: JSONEachRow for the row path, an in-memory Arrow IPC stream for the Arrow path. No network, Kafka or ClickHouse is involved in Lab 01.
- Memory is the process high-water RSS (ru_maxrss) of a fresh process per combination, minus the RSS after the fixture was loaded; the Arrow pool peak covers Arrow-allocated buffers only.
