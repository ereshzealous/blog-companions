S8 · stale-set race
  R1 takes the 1 s lease and reads v10 (₹69,999), then stalls 3 s; the price changes to v11 (₹64,999)
  R2 takes the expired lease and writes v11; R1 wakes and writes v10

  versioned write (never accept an older source version): R1 refused (1 rejected), cache stays v11 (₹64,999)
  an unchanged value may still be re-cached: a v11 refresh over v11 is accepted and renews the TTL
  [ok] assert plain SET regresses the cache
  [ok] assert versioned write keeps v11
  [ok] assert versioned write allows an equal-version refresh
