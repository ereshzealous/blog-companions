================================================================================
DISTRIBUTED SYSTEMS #15 — QUEUE OVERLOAD · TIER 1 DETERMINISTIC SIMULATION
================================================================================

Worked example: order processing during a flash sale.
  normal 5,000/s · capacity 6,000/s · flash sale 12,000/s for 10 min
  dependency: C*=30 service=5ms plateau=6,000/s
  timeliness SLO: oldest message age <= 60 s

  General form:   B_peak = (lambda_s - mu) x D
                  W_max  = B_peak / mu
                  T_rec  = B_peak / (mu - lambda_n)
                  T_rec / D = (lambda_s - mu) / (mu - lambda_n)
  Here:           B_peak = 6,000 x 600 = 3,600,000
                  W_max  = 3,600,000 / 6,000 = 600 s = 10 min
                  T_rec  = 3,600,000 / 1,000 = 3,600 s = 60 min  (6x the spike)
